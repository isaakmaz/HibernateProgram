# Консольное приложение "User Service"

Проект представляет собой консольное приложение для управления пользователями (CRUD-операции). Разработано на Java с использованием Hibernate для взаимодействия с базой данных PostgreSQL, без использования Spring Framework.

Особое внимание уделено качеству кода, архитектуре и полному тестовому покрытию.

### Основные возможности
*   **CRUD-операции:** Создание, чтение, обновление и удаление пользователей.
*   **Архитектура:** Четкое разделение на слои Data Access (DAO) и Business Logic (Service).
*   **Интерактивный интерфейс:** Управление через консольные команды.
*   **Полное тестовое покрытие:**
    *   **Интеграционные тесты** для DAO-слоя с использованием Testcontainers.
    *   **Модульные (юнит) тесты** для Service-слоя с использованием Mockito.
*   **Контейнеризация:** Готовая конфигурация `docker-compose` для быстрого развертывания базы данных.

### Стек технологий
*   **Язык и платформа:** Java 17, Maven
*   **ORM:** Hibernate
*   **База данных:** PostgreSQL
*   **Тестирование:**
    *   JUnit 5
    *   Mockito
    *   Testcontainers
*   **Логирование:** SLF4J + Logback

## Установка и запуск

### Требования
*   Java (JDK 17 или выше)
*   Apache Maven
*   Docker Desktop (должен быть запущен)

### Порядок запуска

**1. Клонируйте репозиторий:**
```bash
git clone https://github.com/isaakmaz/HibernateProgram.git
cd HibernateProgram
```

**2. Запустите базу данных в Docker:**
В корне проекта находится файл `docker-compose.yml`, который настроен для запуска PostgreSQL.
```bash
docker-compose up -d
```
Эта команда скачает нужный образ и запустит контейнер с базой данных в фоновом режиме. База будет доступна по адресу `localhost:5432`.

*Чтобы остановить и удалить контейнер, используйте команду `docker-compose down`.*

**3. Запустите приложение:**
*   Откройте проект в вашей IDE (например, IntelliJ IDEA).
*   Maven автоматически скачает все необходимые зависимости.
*   Найдите и запустите `main` метод в классе `com.example.userservice.Main`.

## Использование

После запуска приложение предложит ввести команду.

*   `create` — создать нового пользователя.
*   `read` — найти пользователя по его ID.
*   `update` — обновить данные существующего пользователя.
*   `delete` — удалить пользователя по ID.
*   `exit` — завершить работу программы.

## Тестирование

Проект имеет высокий уровень тестового покрытия. Все тесты находятся в директории `src/test/java`.

**Для запуска всех тестов** выполните команду Maven в корне проекта:
```bash
mvn clean test
```

#### Интеграционные тесты
Тесты для DAO-слоя (`UserDaoIntegrationTest`) используют **Testcontainers**. Они автоматически поднимают временный Docker-контейнер с чистой базой данных для каждого тестового запуска.
**Важно:** Для их выполнения **не нужно** запускать `docker-compose`. Testcontainers управляет Docker самостоятельно.

#### Модульные (юнит) тесты
Тесты для Service-слоя (`UserServiceTest`) используют **Mockito** для создания "заглушек" (моков) DAO-слоя. Эти тесты выполняются в полной изоляции от базы данных и работают мгновенно.
