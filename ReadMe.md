## Консольное приложение для управления пользователями

Это мое домашнее задание по курсу Hibernate. Нужно было сделать простое консольное приложение, которое умеет создавать, читать, обновлять и удалять пользователей из базы данных.

### Задание:
> Разработать консольное приложение(user-service) на Java, использующее Hibernate для взаимодействия с PostgreSQL, без использования Spring. Приложение должно поддерживать базовые операции CRUD (Create, Read, Update, Delete) над сущностью User.

### Что я использовал:
*   Java 17
*   Maven для сборки и зависимостей
*   Hibernate для работы с базой
*   PostgreSQL в качестве базы данных
*   Docker для запуска PostgreSQL (чтобы не устанавливать ее отдельно)
*   Logback для логирования

### Как запустить проект

**1. Что должно быть установлено:**
*   Java (JDK 17)
*   Maven
*   Docker Desktop

**2. Запуск базы данных в Docker**

Я настроил запуск базы через `docker-compose`. Это удобно, потому что не нужно писать длинную команду в терминале.

*   Откройте терминал (командную строку) в папке, где лежит проект (там же, где `pom.xml`).
*   Выполните команду:
```bash
docker-compose up -d
```

Эта команда сама скачает и запустит контейнер с PostgreSQL в фоновом режиме. База данных будет доступна по адресу localhost:5432.
Чтобы остановить контейнер, можно использовать команду docker-compose down.

3. Запуск самого приложения
Откройте проект в IntelliJ IDEA.
Maven должен сам скачать все нужные библиотеки.
Найдите и запустите main метод в файле src/main/java/com/example/userservice/Main.java.
Команды в приложении

Когда программа запустится, она попросит ввести команду. Вот список команд:
create - чтобы создать нового пользователя.
read - чтобы найти пользователя по ID.
update - чтобы изменить имя или возраст у существующего пользователя.
delete - чтобы удалить пользователя по ID.
exit - чтобы выйти из программы.
